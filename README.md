**杂盒 ZaBox 是一个本地优先的个人起始页：把常用网站、资讯、任务计划和文件工具收进一个新标签页，杂，而有序。**

在线体验：https://zahe.hiitun.top

- **没有账号，不上传你的数据**。编组、站点、计划、设置只存在你自己的浏览器里。同步只走你自己的文件或你自己的 GitHub 私有仓库。
- **网站一多也不怕找不到**。编组加拼音搜索，几百个站点也能一眼定位。
- **不止是导航**。计划、资讯、文件工具都在同一页，不用来回切换。

## 功能亮点

**网站编组（核心）**

- 两种形态随时互换：详细列表（图标加名称加说明）与文件夹式（图标瓷砖堆叠卡）。
- 组合卡：把两张文件夹卡拖拽合并成一张双 tab 卡，tab 可以拖出解组。
- 站点管理：置顶、标签（1–4 个英文字母）、右键编辑与删除、卡片拖拽排序、宽度与高度可调。

**搜索**

顶部搜索框支持中文、拼音首字母（输入 `db` 找豆包）与别名直达，下拉即时预览，回车打开。

**计划**

- 待办：勾选完成、分组、子任务、已完成折叠。
- 长期计划：按次数推进（比如健身打卡 12/30 次）或按截止日期（显示剩余天数、逾期提醒）。
- AI 整理：把一句杂事自动拆成待办与计划，确认后落库。网站版是本地规则拆分，不联网、不需要 Key；桌面版可以接 DeepSeek、OpenAI 或你自己的 API。

**资讯**

AI 资讯、热门话题（微博加百度双源）。

**文件工具（全部本地运行，文件不上传）**

PDF 转图片、PDF 转长图、图片转 PDF、PDF 转 TXT、PDF 合并、PDF 拆分。

**外观**

- 暗夜与白天两档，可调卡片透明度。
- 五套预设：默认、设计师、程序员、工具、我的。改动会自动保存为「我的」预设。
- 背景：星云紫、斑驳光影、深海蓝（可自选纯色），也可以上传本地图片作背景，图片只存本机。

**小组件**

中式色卡（158 色，可收藏）、资讯、热门话题、计划、文件工具，都可以自由排布。

**多端**

- 网站版：在线即用，也支持安装为 PWA。
- 浏览器扩展：新标签页扩展，已提交 Edge 扩展商店审核；Chrome 商店待上架。
- 桌面计划应用：Windows 客户端，置顶小窗、贴边收起、V 收起只留顶栏、系统托盘、GitHub 同步、AI 拆分。在 [Releases](https://github.com/0waitgoo/zabox/releases/tag/plan-desktop) 下载安装包。

## 快速上手

### 在线用（最简单）

直接打开 https://zahe.hiitun.top，不用注册，不用装东西。

### 自己部署到 Vercel（一键）

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/0waitgoo/zabox)

1. Fork 本仓库。
2. 在 Vercel 导入你 Fork 的仓库，框架选 Vite。仓库已带 `vercel.json`，构建命令与输出目录都配好了。
3. 部署完成即得到一个可用站点。根目录 `api/` 下的函数提供资讯、话题、榜单接口，`vercel.json` 里的 Cron 会每天定时预热资讯接口。

基础功能不需要任何环境变量。GitHub 同步需要你自己的 OAuth 应用：在 GitHub 新建一个 OAuth App，把回调地址填成你部署好的站点根地址，再在 Vercel 项目里配 `GITHUB_OAUTH_CLIENT_ID` 与 `GITHUB_OAUTH_CLIENT_SECRET` 两个环境变量。

### 本地运行

```bash
npm install
npm run dev        # 开发服务器，打开终端输出的地址
npm run build      # 构建到 dist/
npm run lint       # 类型检查
```

构建出的 `dist/` 是纯静态文件，可以托管到任意静态服务（Nginx、GitHub Pages、Cloudflare Pages 等）。注意：资讯、热门话题两个组件依赖 `/api` 接口；纯静态托管时这三个组件无数据，但导航、搜索、计划、同步等本地功能全部正常。

## 数据与同步

**本地优先**：所有个人数据只保存在浏览器 `localStorage`，服务端不保存、不收集任何用户数据。换浏览器或清缓存会回到初始数据，请用下面的方式备份或同步。

在页面右上角「数据」菜单里，有四种方式（可叠加使用）：

| 方式 | 说明 | 门槛 |
| --- | --- | --- |
| 导出 / 导入 JSON | 一键把全部数据导出为一个 JSON 文件，换设备时导入即可恢复 | 无 |
| 本地文件保存 | 指定一个本地 JSON 文件，数据变化后自动写回（也支持手动点保存） | Chrome / Edge（File System Access API）；其他浏览器退化为下载 |
| GitHub 同步 | 把数据存进你自己的一个私有 GitHub 仓库，多设备自动拉取、写回 | GitHub 账号（点一次登录授权） |
| 恢复默认 | 回到内置初始数据 | 无 |

**GitHub 同步设置（点一次登录）**

1. 打开本站「数据 → GitHub 同步」，点「使用 GitHub 登录」。
2. 在 GitHub 官方授权页确认授权。本站走 OAuth 登录，不接触你的 GitHub 密码，不用生成、粘贴任何令牌。
3. 登录成功后，会自动在你的账号下创建一个**私有**仓库 `ainav-data` 并开启同步：每次打开页面自动拉取最新数据，你的修改会在几秒后自动写回仓库（每次写回是一个 commit，历史可查可回滚）。
4. 其他设备打开同一站点，同样点一次 GitHub 登录即完成配对。

**冲突处理**：两台设备同时改动时，按数据自带的更新时间裁决，较新的胜出；实在裁不下，菜单里会让你选「以云端为准」或「以本地为准」，不会静默丢数据。

**安全说明**：登录凭证只保存在你本机的浏览器里，不会进入同步的 JSON，也不会出现在导出文件里；同步仓库是你的私有仓库，你随时可以在 GitHub 设置里撤销本站的授权。

## 常见问题

**换浏览器或清缓存，数据没了怎么办？**

数据默认只存本机浏览器，这是本地优先的设计。用「数据」菜单导出 JSON 备份，或者开 GitHub 同步，换设备登录即恢复。

**资讯、热门话题没有数据？**

这两个组件依赖 `/api` 接口。纯静态托管（比如只丢 `dist/` 到静态空间）时没有接口，自然无数据；官方站与正常 Vercel 部署不受影响。

**GitHub 登录失败怎么办？**

先确认部署站点的回调地址与 OAuth 应用里填的回调地址一致；授权页需要放行 repo 权限。仍失败时，把页面上的报错原文贴到 Issue 里。

**桌面版安装时出现 SmartScreen 提示？**

安装包目前未签名，点「仍要运行」即可安装。签名与应用内自动更新在路线图里。

## 技术栈

React 19 + Vite 6 + TypeScript + Tailwind CSS 4；资讯接口为 Vercel Serverless Functions（根目录 `api/`），另有等价的 Express 实现（`server/`）供自托管；排行榜数据由 GitHub Actions 每周更新（需配 `PRODUCT_HUNT_TOKEN` 才有真实数据）。
