# 杂盒计划 0.1.1：Windows 兼容性修复

## 行为变化

- 顶栏收起/展开只保存、恢复物理像素的内容区尺寸；降低最小高度后再收起，快速点击串行执行。
- 标题栏拖拽直接移动窗口，不启动 Windows 标题栏贴靠，拖到屏幕边缘不会变成半屏。
- 拖拽松手后才判断贴边收起；使用当前显示器工作区和缩放比例，排除任务栏区域。删除每 500ms 改位置/尺寸的轮询。
- 最大化不再被后台自动撤销。细条模式点最大化会先恢复正常内容区。
- 默认不强制置顶；托盘显示、重复启动统一先取消最小化，再显示并聚焦；任务栏激活可以恢复移出屏幕的窗口。
- 首次启动默认不透明；用户设置的透明度继续保留。
- GitHub 登录改为系统浏览器授权，经本机回调返回软件，不再要求设备确认码。收起窗口或打开设置不会卸载登录组件。

## 发布依赖

必须先把本分支的**网站部分**部署到 `https://zahe.hiitun.top`，再分发桌面安装包。
桌面端复用网站已经配置的 GitHub OAuth App、根路径回调及 `/api/github-oauth` 换码接口。
不需要把 OAuth secret 放进安装包，也不需要给 GitHub OAuth App 改成本机回调地址。

流程：桌面绑定随机本机端口 → 浏览器打开网站并保存会话 → GitHub 回到原网站根路径 → 网站验证 OAuth state → 仅把授权码发送到 `127.0.0.1` → 桌面验证独立的随机 state → 经已有服务器换 token。

本机回调仅监听回环地址；等待上限 180 秒；取消会关闭监听；错误 state 不消耗登录；授权码不写日志，凭证不进入同步 JSON。

## 验证

- `npm test`：窗口循环、DPI、快速连点、最大化、移动细条后展开、失败恢复、负坐标显示器、任务栏工作区、登录回跳及拒绝授权。
- `npm run lint`、`npm run build`、`npm run build:plan`。
- Windows CI：`cargo test` 运行回调解析和真实 TCP 回调测试；Tauri 构建 exe/msi，PR 的测试安装包保存在 Actions artifacts，不覆盖正式 Release。

## Windows 实机验收（不能由网页构建替代）

1. 100% / 125% / 150% / 200% 缩放下，连续收起展开 20 次，观察窗口宽高稳定。
2. 快速连点收起/展开、细条拖到别处再展开、细条最大化再还原。
3. 拖到左右上下边缘，确认不触发半屏、鼠标悬停细边可恢复；检查左右副屏和负坐标显示器。
4. 点击任务栏最小化/恢复；点托盘隐藏/恢复；从托盘菜单显示；最小化后重复启动。
5. 登录、取消登录、授权被拒绝、浏览器回跳、超时后重试；登录等待时收起/展开和切换设置页。
6. 拖动、缩放、最大化、切换页面后检查是否再出现空白或无响应。若仍出现，记录 WebView2 版本及窗口操作错误。
