# 杂盒计划 0.1.4

设置新增「窗口行为 → 点击关闭时最小化到任务栏」，默认开启并在本机保存。开启后右上角 ×、收起条 ×、贴边条 × 和系统关闭请求均最小化到任务栏，程序继续运行。关闭开关后恢复关闭窗口。

贴边隐藏的窗口会先恢复位置再最小化，避免任务栏恢复后仍在屏外。最小化失败时报告错误，不改为隐藏或关闭。系统托盘右键「退出」始终可彻底退出。

单元测试覆盖默认值、持久化、两种行为和失败处理；Windows Edge 检查开关与按钮提示、重启后的偏好恢复。原生任务栏恢复仍需 Windows 安装验收。

空白处右键新增「新建待办」「新建长期计划」：自动返回主视图，聚焦原有输入框或打开长期计划表单。复用原有数据和保存逻辑；任务条目保留编辑/删除菜单，输入框保留系统编辑菜单。新菜单支持 Esc、点外关闭、方向键和边缘定位。

窗口按形状自动切换布局：竖向为「待办 / 长期计划」横排页签，一次显示一个分类；横向为左右双列同时显示。列表各自滚动，添加入口固定在底部。调整窗口时保留当前分类和表单草稿；右键创建会切到对应分类。网站布局不变。
