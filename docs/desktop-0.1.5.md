# 杂盒计划 0.1.5

登录、同步、AI 整理与窗口按钮合并到顶部同一行。未登录时不显示同步；AI 整理仅保留图标和悬停提示。授权等待、取消、同步反馈保留在单行控件和提示中。

设置的关闭开关改为「点击关闭时收进托盘」，沿用原有本机偏好。开启后右上角 × 隐藏窗口，并通过 setSkipTaskbar(true) 移除运行中的任务栏按钮；托盘单击/显示窗口/重复启动恢复时设回 false。关闭开关后仍实际关闭窗口，托盘退出保持不变。

隐藏失败时恢复任务栏按钮并报错，不转为退出。登录组件始终挂载，收起窗口或打开设置不会中断授权。

收起条展开时读取当前显示器工作区：下方空间不足则向上展开，菜单栏移到窗口底部并与收起条的底部位置对齐。再次收起保留该锚点；移到较高位置再展开会恢复顶部菜单栏。跨到较小显示器时限制窗口尺寸与位置，避免越过任务栏。

手动拉大收起条的宽度或高度时自动退出收起模式，按用户拉出的尺寸显示完整内容；过小高度提升到普通窗口最小高度。窗口程序内部收起/展开产生的 resize 事件走同一队列，不会误判为手动拉大。

收起条固定为适合按钮内容的紧凑宽度（232 逻辑像素，随系统缩放），不再沿用完整窗口宽度。展开恢复原窗口尺寸。

鼠标悬停收起条 220ms 后临时展开预览，离开整个窗口 300ms 后回到原短条位置；回到窗口会取消收起。预览时手动拉大窗口会固定为普通窗口。
