# 杂盒计划 0.1.7

快捷键默认 Ctrl + `，改为完整窗口/短条切换；从托盘或贴边状态按下始终恢复完整窗口。设置中点击组合键后直接按键录入，Esc 取消，失焦取消。录入期间暂时注销旧热键，保存后恢复；支持取消勾选，组合键和勾选分别记忆。新热键被占用时保留旧设置并提示错误。

登录前检查官网授权协议版本，旧网站会直接显示“官网授权页面尚未更新”，不再无意义等待。整体授权等待限制为两分钟，错误详情在窗口内可见。

**上线依赖**：官网当前仍是旧版，必须部署本分支的 main.tsx、desktopLoginBridge.ts 和 OAuth 配置版本更新，才能完成 GitHub 回跳。安装包不能单独替代网站发布。
