杂盒 ZaBox 隐私说明

适用产品：杂盒 ZaBox 网站版与浏览器扩展版 · 生效日期：2026-10-24

一、我们不收集你的个人数据

杂盒 ZaBox 不会收集、存储或上传你的任何个人数据。你的网站编组、站点、任务计划、布局设置、壁纸与显示偏好，全部只保存在你自己浏览器的本地存储（localStorage）中，只存在于你的设备上，开发者无法访问。

二、联网只做一件事：拉取公共内容

产品仅从 https://zahe.hiitun.top 拉取面向所有用户的公共内容数据（AI 资讯、热门话题、AI 软件榜），用于在页面上展示。拉取请求是普通的只读请求，不携带你的个人数据、浏览记录或任何身份标识。

三、可选的 GitHub 同步（由你主动开启）

如你选择开启 GitHub 同步，你的数据将通过 GitHub 官方接口直接写入你自己账号下的私有仓库，同步过程不经过开发者的服务器。你填写的 GitHub 令牌只保存在本地浏览器中，不会发送给开发者或任何第三方。不开启同步时，产品不会访问 GitHub。

四、文件工具全本地处理

文件工具（PDF / 图片转换等）全部在你的浏览器本地运行，你选择的文件不会上传到任何服务器。

五、统计与追踪

本产品不集成任何统计、分析、广告或用户追踪组件。

六、扩展权限

浏览器扩展版申请以下权限：本地存储（storage，用于保存你自己的数据与设置）、数据接口域名（zahe.hiitun.top）的访问权限（仅用于只读拉取公共内容）、标签页（tabs，仅在你点开扩展图标添加网站时，读取当前标签页的标题与网址，用于填入添加面板；不读取浏览历史、不读取任何网站的页面内容）、侧边栏（sidePanel，用于在浏览器侧边栏里打开杂盒主页）。除此之外不申请任何权限。
